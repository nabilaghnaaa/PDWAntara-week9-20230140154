STUDY TOOLS

Tools untuk Membantu Kegiatan Belajar

Gunakan beberapa tools sederhana berikut untuk mengatur tugas, mencatat materi, dan membuat waktu belajar lebih teratur.

Daftar Tools

Pilih tools sesuai dengan kebutuhanmu.

01 PLANNING

Study Planner

Membantu menyusun jadwal belajar berdasarkan mata kuliah dan aktivitas yang perlu diselesaikan.

02 TASK

Task List

Catat tugas kuliah yang harus diselesaikan dan gunakan daftar untuk memantau pekerjaan.

03 NOTES

Quick Notes

Tempat untuk menyimpan catatan singkat, ide, atau poin penting dari materi perkuliahan.

04 FOCUS

Focus Timer

Atur waktu belajar agar kamu dapat berkonsentrasi pada satu aktivitas dalam satu waktu.

05 REFERENCE

Study Resources

Simpan daftar referensi seperti buku, artikel, website, atau materi yang digunakan untuk belajar.

06 SCHEDULE

Class Schedule

Catat jadwal perkuliahan agar kamu dapat mengetahui agenda kelas yang harus diikuti.

Tools tidak ditemukan

Silakan coba kata kunci lainnya.

CATATAN

Gunakan tools sesuai kebutuhan.
